# ⚾ EasyBall

컴투스프로야구V 스타일의 **세로형 모바일 야구 게임**입니다.
별도 빌드/서버 없이 `index.html` 단일 파일로 동작하는 웹앱입니다. (외부 라이브러리 없음)

## 실행 방법

`index.html`을 브라우저로 열기만 하면 됩니다. (모바일 세로 화면에 최적화)

```bash
# 예: 로컬 서버로 실행
python3 -m http.server 8000
# → http://localhost:8000
```

## 아웃게임 (성장 시스템)

- **선수단**: 타자 4스탯(컨택/파워/선구/주루), 투수 4스탯(구위/제구/변화/체력), 등급(노멀/레어/엘리트/레전드)
- **훈련**: 대성공/성공/실패 판정으로 스탯·EXP 획득, 레벨업 시 스탯 자동 상승, 최대 레벨 시 골드로 **승급**
- **특성 시스템**: Lv.5부터 특성 훈련 — 거포·교타자·침착·대도·닥터K·제구 마스터·철완·강심장·싸움닭, 인게임/벤클에 실제 효과 반영
- **구단 시설**: 타격 훈련장·불펜(훈련 EXP 증가), 웨이트장(대성공 확률·벤클 HP 증가)
- **팀 장비 강화**: 배트(장타력·벤클 공격), 글러브(제구), 스파이크(주루·벤클 속도)
- **스카우트**: 1연차 / 10연차(레어 이상 1명 보장)
- **업적**: 통산 승수·홈런·훈련·벤클 승리 등 10종 도전 과제와 골드 보상
- 진행 상황은 `localStorage`에 자동 저장 (구버전 세이브 자동 마이그레이션)

## 인게임 (3D · 3이닝 경기)

- **자체 3D 원근 투영 엔진**: 포수 시점 카메라로 마운드·내야·외야 펜스를 원근감 있게 렌더링
- **투구 궤적**: 구종별(직구/슬라이더/커브/체인지업/포크) 휘어지는 3D 궤적과 잔상 트레일, 도착 예측 마커
- **타구 궤적**: 타격 순간 방송 중계처럼 **부감 카메라로 전환**, 탄도+바운드 물리 시뮬레이션으로 홈런/안타/파울 궤적과 지면 그림자 표시
- **타격**: 타이밍 스윙 — PERFECT/GOOD/파울/헛스윙 판정, 선수 스탯·장비·특성 반영
- **투구**: 구종 선택 → 존 터치 조준 → 게이지 타이밍 제구, 투수 체력 관리
- 볼카운트/주자/아웃 자동 진행, 끝내기·3회초 리드 조기 종료, 난이도 3종

## 벤치 클리어링 (턴제 RPG)

- 몸에 맞는 공(사구)이 나오면 확률적으로 **벤치 클리어링** 발동 — 몸쪽 위협구를 던지면 직접 유발할 수도 있습니다
- 발동 시 **3 vs 3 턴제 전투**로 전환: 에이스 투수 + 거포 + 주장 vs 상대 선발진
- 야구 요소 스킬: 투수 **강속구 투척**(스턴), 타자 **풀스윙**(고위력·빗나감 위험), 기본 **몸싸움**
- **사기 게이지**를 모아 필살기 **벤치 클리어 러시**(전원 총공격) 발동
- 승리 시 잔여 경기 동안 팀 버프(타격 판정 범위 확대·투구 게이지 감속) + 보너스 골드, 패배 시 디버프

## 기술

- 순수 HTML + CSS + Canvas + Vanilla JS 단일 파일
- 자체 구현 3D 카메라 투영/언프로젝션, 탄도 물리, WebAudio 효과음
