# ⚾ EasyBall

컴투스프로야구V 스타일의 **세로형 모바일 야구 게임**입니다.
별도 빌드/서버 없이 `index.html` 단일 파일로 동작하는 웹앱입니다.

## 실행 방법

`index.html`을 브라우저로 열기만 하면 됩니다. (모바일 세로 화면에 최적화, 데스크톱에서도 동작)

```bash
# 예: 로컬 서버로 실행
python3 -m http.server 8000
# → http://localhost:8000
```

## 아웃게임 (성장 시스템)

- **선수단**: 타자 4스탯(컨택/파워/선구/주루), 투수 4스탯(구위/제구/변화/체력), 등급(노멀/레어/엘리트/레전드)
- **훈련**: 골드를 소모해 훈련 — 대성공(15%) / 성공(60%) / 실패(25%)로 스탯·EXP 획득
- **레벨업 / 승급**: EXP로 레벨업(스탯 자동 상승), 최대 레벨 도달 시 골드로 상위 등급 승급
- **스카우트**: 골드로 신규 선수 영입 (노멀 60% / 레어 30% / 엘리트 9% / 레전드 1%)
- **라인업**: OVR 상위 타자 9명 + 최고 투수가 자동 편성, 방출로 로스터 정리
- 진행 상황은 `localStorage`에 자동 저장

## 인게임 (3이닝 경기)

- **타격(공격)**: 포수 시점으로 날아오는 공을 타이밍에 맞춰 스윙 — PERFECT / GOOD / 파울 / 헛스윙 판정, 선수 스탯이 안타·홈런 확률에 반영
- **투구(수비)**: 구종 선택 → 스트라이크 존 터치로 코스 조준 → 게이지 타이밍으로 제구, 투수 체력 관리
- 볼카운트/주자/아웃/이닝 자동 진행, 3회초 리드 시 조기 종료·끝내기 처리
- 난이도 3종(쉬움/보통/어려움), 승리·득점에 따라 골드와 라인업 EXP 보상

## 기술

- 순수 HTML + CSS + Canvas + Vanilla JS (외부 의존성 없음)
- WebAudio 기반 간단 효과음
